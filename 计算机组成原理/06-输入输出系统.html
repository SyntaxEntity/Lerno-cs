计算机组成原理 ｜ 输入输出系统

计算机组成原理 · 输入输出系统

输入输出系统 [高频]

考频　考察次数 20 次；涉及年份：2010、2012、2014、2016、2018、2020、2022、2023、2025；分数占比约 10%；主要题型：选择题 + 综合应用题（中断、DMA、磁盘时间计算）。

核心讲解

I/O 接口（设备控制器）的作用是数据缓冲、格式转换、状态与命令寄存、地址译码，它把 CPU 的高速并行总线与设备的低速串行工作方式解耦。I/O 端口的编址有两种：统一编址（把端口当作主存单元，用普通访存指令访问，无需专门指令但占用主存地址空间）与独立编址（有独立的地址空间与专用 IN/OUT 指令，不占主存空间但指令类型增多）。I/O 控制方式的发展主线是CPU 干预程度逐步降低：程序查询方式下 CPU 不断读状态寄存器空转等待，CPU 与设备完全串行；

程序中断方式下 CPU 发出命令后继续执行原程序，设备就绪时用中断通知 CPU 在一条指令执行结束后响应，数据传送仍需 CPU 用指令搬入主存；DMA 方式由 DMA 控制器直接在主存与设备之间成块传送，数据不经过 CPU 的寄存器，每传送一个字（或一个数据块）占用一次总线（周期挪用/周期窃取），只有在传送前（初始化）与传送后（中断处理）才需要 CPU 参与；通道方式由通道处理器执行通道程序，进一步把 CPU 从 I/O 管理中解放出来。

中断系统要点：CPU 响应中断的条件是"有中断请求 + 中断允许触发器为 1 + 当前指令执行结束"；响应时由硬件自动执行中断隐指令完成三件事——关中断、保存断点（PC）、取中断向量；随后由中断服务程序保存现场并执行服务。

多重中断（中断嵌套）靠中断屏蔽字控制：屏蔽字中某位为 1 表示屏蔽（禁止）对应的中断源，因此优先级越高的中断源，其屏蔽字中"1"的位数越多。磁盘的性能指标是存取时间，存取时间 = 寻道时间 + 旋转延迟 + 传输时间，其中平均旋转延迟为旋转半圈的时间 60 / (2 × 转速)（转速单位 rpm）；数据传输率与位密度、转速（线速度）相关，数据传输率 = 每条磁道的容量 / 旋转一圈的时间。固态硬盘 SSD 基于闪存，无机械寻道与旋转延迟，随机访问快，但存在写放大、擦除次数受限（寿命）的问题。

关键结论速记

  • 四种 I/O 方式 CPU 干预程度：程序查询 > 程序中断 > DMA > 通道 —— 判据是"CPU 是否需要在传送过程中持续参与"。
  • DMA 数据不经过 CPU 寄存器，直接在主存与设备间传送 —— 这是 DMA 与程序中断方式的本质区别。
  • 中断隐指令由硬件执行：关中断、保存断点、取中断向量 —— 它是"指令"但不是程序里的指令。
  • 中断响应时机：一条指令执行结束后 —— 而不是任意时刻，也不是一个时钟周期后。
  • 屏蔽字为 1 表示屏蔽，优先级越高屏蔽的位数越多 —— 多重中断靠它实现嵌套。
  • 磁盘存取时间 = 寻道 + 旋转延迟 + 传输，平均旋转延迟 = 60 / (2 × 转速) 秒 —— 旋转延迟取半圈。

易错点

  • 认为 DMA 传送完全不需要 CPU 参与：DMA 只在数据传送过程中不需要 CPU 干预，传送前的初始化（设置主存地址、设备地址、传送长度、方向）与传送结束后的中断处理都必须由 CPU 完成。
  • 把中断响应时机写成"任意时刻"或"一个时钟周期后"：可屏蔽中断只在一条指令执行结束后响应（这样断点才是一条指令的边界）；若在指令中间响应，断点无法正确保存。
  • 混淆中断隐指令与中断服务程序：中断隐指令是硬件自动执行的（关中断、保存断点、取中断向量），而保存现场、执行设备服务、恢复现场是中断服务程序（软件）做的，两者不能混为一谈。
  • 磁盘旋转延迟算成一圈：平均旋转延迟是旋转半圈的时间，即 60 / (2 × 转速) 秒；若按一圈计算，存取时间会偏大一倍。

真题示例

2012 年真题改编（单项选择题，2 分）

某磁盘的转速为 7200 rpm，平均寻道时间为 8 ms，数据传输率为 20 MB/s。若读取一个 4 KB 的磁盘块，则平均存取时间约为（ ）。

A. 4.2 ms　B. 8.2 ms　C. 12.4 ms　D. 16.5 ms

解析：平均存取时间由三段相加。平均旋转延迟 = 60 / (2 × 7200) s = 4.17 ms（旋转半圈）；传输时间 = 4 KB / 20 MB/s = 4096 B / (20 × 10^6 B/s) ≈ 0.205 ms；再加上平均寻道时间 8 ms，得 8 + 4.17 + 0.205 ≈ 12.37 ms，最接近 C。干扰项 D（16.5 ms）正是把旋转延迟误算成一整圈（8.33 ms）的结果，B（8.2 ms）则是完全漏算旋转延迟的结果。判分点是旋转延迟必须取半圈，以及单位换算（rpm 转秒要除以 60、KB 与 MB 统一为字节）。
