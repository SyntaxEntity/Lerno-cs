计算机组成原理 · 数据表示与运算

数据表示与运算 [高频]

考频　考察次数 26 次；涉及年份：2009—2025 年高频，2010、2012、2015、2017、2019、2021、2023 年为典型年份；分数占比约 12%；主要题型：选择题 + 43/44 题计算。

核心讲解

定点数的编码有四种：原码（最高位符号位，其余为绝对值）、反码（负数在原码基础上数值位取反）、补码（负数在反码基础上末位加 1）、移码（在补码基础上符号位取反，用于表示阶码）。n 位补码表示范围是 -2^(n-1) 到 2^(n-1)-1，比原码、反码多表示一个负数 -2^(n-1)，且 0 的表示唯一；n 位移码范围是 -2^(n-1) 到 2^(n-1)-1，其无符号数值大小顺序与真值顺序一致，所以移码适合做浮点数的阶码比较。

补码运算的溢出判断有两种等价方法：一是双符号位（变形补码）结果的两个符号位为 01 表示正溢出、10 表示负溢出；二是单符号位下判断"最高位进位 C_n 与次高位进位 C_(n-1) 是否异或为 1"。IEEE 754 单精度共 32 位，字段为 1 位符号 + 8 位阶码 + 23 位尾数，阶码用偏移量 127 的移码（E = e + 127），规格化数的尾数隐含最高位的 1（即 1.M），故真实有效位是 24 位。

特殊值约定：阶码全 0 且尾数全 0 表示 ±0；阶码全 0 而尾数非 0 表示非规格化数（此时隐含位为 0，用于表示接近 0 的数）；阶码全 1 且尾数全 0 表示 ±inf；阶码全 1 而尾数非 0 表示 NaN。浮点数加减的五个步骤是：对阶（小阶向大阶看齐，尾数右移，移出的位保留为保护位）、尾数加减、规格化（左规或右规，右规一次阶码加 1）、舍入（常用就近舍入即"0 舍 1 入"）、判溢出（阶码溢出才是真溢出，尾数溢出可用右规纠正）。C 语言中 int 到 float 的转换会因 float 只有 24 位有效位而丢失低位，float 转 int 是向零截断，这些都必须在位级上理解。

关键结论速记

  • n 位补码范围 [-2^(n-1), 2^(n-1)-1]、原码/反码范围 [-(2^(n-1)-1), 2^(n-1)-1] —— 补码比原码多一个负数，0 唯一。
  • 补码取负 = 全部位取反加 1；-128 的 8 位补码是 1000 0000 —— 该值没有对应的原码与反码。
  • 移码 = 补码的符号位取反、IEEE 754 阶码偏移量为 127（单精度）/ 1023（双精度） —— 偏移量与"移码"的常数不要混淆。
  • IEEE 754 单精度：1 + 8 + 23，隐含 1.M，真实有效位 24 位 —— 精度由尾数位数决定，范围由阶码位数决定。
  • 溢出判断：C_n 异或 C_(n-1)，或双符号位 01/10 —— 只有同号相加才可能溢出。
  • 浮点加减顺序：对阶 → 尾数运算 → 规格化 → 舍入 → 判溢出 —— 对阶一定"小阶向大阶看齐"。

易错点

  • 混淆移码偏移量与 IEEE 754 偏移量：n 位纯移码是"补码符号位取反"（偏移 2^(n-1)），而 IEEE 754 单精度的阶码偏移量是 127（双精度 1023），两者不能互相代入。
  • 认为补码与原码表示范围相同：n 位补码比原码、反码多一个负数 -2^(n-1)，且 -2^(n-1) 不存在对应的原码与反码形式；此外补码的 0 表示唯一，原码与反码有 +0、-0 两种表示。
  • 把尾数溢出当成浮点溢出：尾数相加出现 1x.xxx 只是尾数溢出，可通过右规（尾数右移一位、阶码加 1）纠正；真正的溢出是阶码超出可表示范围，上溢才报错、下溢按机器零处理。
  • 对阶时方向搞反：必须小阶向大阶看齐（阶码小的数尾数右移），若反过来会让阶码变大而尾数左移，导致高位丢失、结果错误。

真题示例

2011 年 408 第 13 题（单项选择题，2 分）

float 型数据通常用 IEEE 754 单精度浮点格式表示。若编译器将 float 型变量 x 赋值为 -12.5，则该变量的机器数是（ ）。

A. 0xC1480000　B. 0xC1480001　C. 0xC1480002　D. 0xC1480003

解析：分三步。第一步，把 -12.5 化为二进制并规格化：12.5 = 1100.1B = 1.1001B * 2^3。第二步，填字段：符号位 S = 1（负数）；阶码 E = 真值阶 3 + 偏移 127 = 130 = 10000010B；尾数 M = 1001 后面补 0 到 23 位，即 10010000000000000000000。第三步，拼接并写成十六进制：1 10000010 10010000000000000000000 按 4 位分组为 1100 0001 0100 1000 0000 0000 0000 0000，即 0xC1480000。答案为 A。关键是把 -12.5 正确写成 1.1001B * 2^3，并把偏移量 127 加到真值阶上。
