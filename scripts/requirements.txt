# 408 速成资料 · Python 侧依赖（锁定版本）
#
# 装到仓库内的 .tools/venv（.tools/ 已 gitignore，可随时删掉重建）：
#
#   python3 -m venv .tools/venv
#   .tools/venv/bin/python -m pip install -r scripts/requirements.txt
#
# 为什么锁定版本：`validate.py` 的 F14 用真实 Markdown 渲染器断言「六段字段各自
# 独立成段」，换版本可能改变段落切分，校验结论就会跟着变。锁定后用同一套版本
# 重跑，结论才可复现；这也保证**本地校验与 CI 门禁用的是同一个版本**——
# 否则门禁通过不等于本地通过。
#
# 依赖缺 markdown 时 F14 直接报 error（不是跳过）——D-06「门禁禁止静默降级」：
# 「没检查」必须与「检查通过」在输出上可区分。锁定版本是为了让结论可复现：
# 中文全角括号的强调判定在 3.10/3.11 之间变过，版本不同结论会不同。
#
# Node 侧依赖（mermaid 真实解析 + 站点内置运行时）另见 tools-package.json ——
# 版本只在那一份清单里写一次，这里不重复（否则就是第二份数据源，迟早漂移）：
#   mkdir -p .tools && cp scripts/tools-package.json .tools/package.json
#   npm install --prefix .tools --cache /tmp/npm-cache --no-audit --no-fund
