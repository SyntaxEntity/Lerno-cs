# `assets/site.css` 类选择器清单（408 侧，供数学二合并）

> 出具方：`website/408-kaoyan`。用途：U1 第 ② 步「合并选择器」的输入。
> 依据：`../PLAN-对齐与改版.md` §5.2.2。**落成文件而不是只在对话里说**——兄弟目录可读。
>
> **配色不在本文件范围内**：按 §5.2.2，配色一律以「A 暖纸」token 表为唯一依据，
> 两边现有取值（含 408 现用的冷灰系）**一律让位**。本文件只交代**类名与用途**。

## 0. 读法

- 「归属」三档：
  - **六段组件** —— 六个小节的容器/标签，两边都必须有（`#sec-*` 是契约锚点）。
  - **共用外壳** —— 契约 §2.3/§2.4.1 钉住的类名，两边必须逐字一致。
  - **项目特有** —— 408 的内容形态需要（如 `kp` 考点卡片、`hs-*` 首页卡片），
    数学二**可留可删**，请按自己的内容形态决定；删掉不影响契约。
  - **状态类** —— 由 `site.js` 在运行时添加，不是静态 HTML 里的。
  - **可删** —— 408 侧已确认无用，合并时直接丢弃。
- 408 在 `site.css` 里定义 **55** 个类；另有 **3 个**类出现在 HTML 但 CSS 里
  **没有规则**（`.sec-core` `.sec-freq` `.cn-prev`，见 §1 末与 §3）。

## 3. ⚠️ 三个「有类名、无规则」

| 类 | 现状 | 说明 |
| --- | --- | --- |
| `.sec-core` | **无任何规则** | 只有 `.sec` 的通用样式生效——**漏配** |
| `.sec-freq` | **无任何规则** | 同上 |
| `.cn-prev` | **无单独规则** | 靠 `.chapter-nav a` 继承基础样式，**可用但脆弱** |

前两个不是"死类"，是**漏配**：生成器会输出 `class="sec sec-core"` 与
`class="sec sec-freq"`。统一版请一并补上（正好用 §5.2.2 的 `--sec-core` / `--sec-freq`）；
`.cn-prev` 建议也补一条对称规则，免得"上一章"的样式完全依赖"下一章"那条规则之外的通用样式。

## 5. 状态类（由 `site.js` 运行时添加，CSS 里必须有对应规则）

| 类 | 何时加 | 用途 |
| --- | --- | --- |
| `.dark` | 挂在 `<html>` 上，`site.js` 按 `localStorage['kaoyan-theme']` 切换 | 深色模式；覆盖同一批 token（**契约要求，勿删**） |
| `.cur` | 侧栏 `.sb-chap` / `.toclink` 的当前项 | 高亮当前章节 / 当前小节 |
| `.navopen` | 挂在 `<body>` 上，点 `.nav-toggle` 时切换 | 窄屏抽屉展开（**契约要求，勿删**） |
| `.on` | 加在 `.to-top` 上（滚动超过 500px） | 让「回到顶部」显现 |

> 前三个在静态 HTML 里**不会出现**，所以"grep 生成物找不到"是正常的，
> **不要当成死类删掉**。`site.js` 直接查询/切换它们。

## 6. 可删的死类

| 类 | 判定 | 理由 |
| --- | --- | --- |
| `chapter-flex-direction` | ❌ **误报，不是类名** | 它来自 `@media` 里的 `flex-direction:column`，是 408 清点脚本的假阳性，**不存在这个类** |

**结论：408 侧没有真正的死类。** 55 个类全部有用途：
- **49 个**在生成物静态出现（含 `.cur`：侧栏当前项由生成器标好）
- **3 个**纯运行时状态类：`dark` `navopen` `on`
- 另有 **3 个**"HTML 用了但 CSS 里没有规则"：`.sec-core` `.sec-freq`（§3）
  与 `.cn-prev`（它靠 `.chapter-nav a` 继承，见 §1 末尾的说明）——
  这三个**不计入 55**，因为 408 的 CSS 里没有它们的规则。

合并时**请全部保留**已定义的 55 个；缺规则的见 §3。

## 6.5 六段标题的统一形态：`.sec-h`（来自 `../配色候选/组件预览.html`）

408 现在**没有** `.sec-h`：六段标题靠 `.lab::before`（统一 `--acc` 色块）+
`.sec-key` 的浅底块。而用户选定的预览里，六段标题是**统一的色条形态**：

```html
<div class="sec-h" style="border-left-color:var(--<语义色>)">考频统计</div>
```

| 小节 | 预览写法 | **应改用的契约 token** |
| --- | --- | --- |
| 考频统计 | `var(--freq)` | `var(--sec-freq)` |
| 核心讲解 | `var(--acc)` | `var(--acc)`（= `--sec-core`） |
| 关键结论速记 | `var(--key)` | `var(--sec-key)` |
| 示意图 | `var(--fig)` | `var(--sec-fig)` |
| 易错点 | `var(--err)` | `var(--sec-err)` |
| 真题示例 | `var(--real)` | `var(--sec-real)` |

> **⚠️ 预览里的 token 名是简写，不要照抄**：它写的是 `--accsoft` `--codebg`
> `--warnbg` `--warnline` `--realbg` `--realline`，以及语义色 `--freq` `--key`
> `--fig` `--err` `--real`。契约 §5.2.2 明令成对用 `-bg`/`-line` 后缀、语义色
> 带 `--sec-` 前缀，且**已把上面这些简写列为废弃旧名**。以契约表为准。

**对 408 的影响**：统一版若采用 `.sec-h` 色条形态，408 要做的适配是
生成器把六段标签从 `<p class="lab">考频统计</p>` 改成
`<div class="sec-h" style="border-left-color:var(--sec-freq)">考频统计</div>`，
并去掉 `.sec-key` 的浅底块（避免"色条 + 色块"重复编码）。
**这属于生成器改动**（`build_html.py` 的 `_style_fields`），408 已记下，
待统一版 `site.css` 到手后一并做，不在本次类清单范围内。

## 7. ⚠️ 408 侧仍需处理的技术债（合并时请一并考虑）

1. **元素选择器大量存在，不是"已全部改成类"**（更正本文件早期的一处臆断）。
   408 现在的 `site.css` 里仍有这些**裸标签规则**：
   `html` `body` `main` `h1` `h2` `h3` `p` `blockquote` `code` `pre`
   `table` `th` `hr` `a`。
   契约钉住的是**类名与 DOM 层级**，裸标签规则不违反契约；但两站合并时
   数学二必须知道：**408 的排版有一部分挂在标签上**，只合并类选择器会丢样式。
   建议统一版把关键的几个（`h1`/`h2`/`pre`/`table`）保留为标签规则，两边一致即可。
2. **还有 9 个已废弃旧名 token 在使用**（§5.2.2 明令替换）：
   `--warn` → 应为 `--warn-bg`；`--dark` `--dark-fg` → 应删除（深色由 `html.dark`
   覆盖同一批 token 实现）。
3. **408 缺 9 个契约 token**（合并时请从「A 暖纸」表补入）：
   `--chip` `--acc2` `--ok` 已有但语义色五个缺失——
   缺 `--sec-freq` `--sec-core`(=`--acc`) `--sec-key` `--sec-fig` `--sec-err`
   `--sec-real`，以及非颜色 token `--topbar-h` `--sans` `--serif` `--sh`
   与 `--real-bg` `--real-line`。

## 8. 合并时请特别注意（形态冲突）

1. **`.sec-key` 的浅底块**是 408 的形态（把速记整段做成色块）。若统一版改成
   六段统一色条，请把 `.sec-key` 的 `background` 一并去掉，避免"既有色条又有色块"。
2. **`.lab::before` 的左侧色块**目前统一用 `--acc`。若六段按 `--sec-*` 着色，
   这里应改成跟随所在小节的颜色（需要 `:is()` 或逐节写）。
3. **`.errs li::before` 的「易错」标记**用了写死的红色（`#b42318` / `#fee4e2`），
   深色模式另写一份（`#ffb4ab` / `#3d1a17`）。统一版建议改用 `--sec-err` 派生。
4. **`.q-stem` / `.q-src`** 用的是 `--acc-soft` / `--acc`；既然语义色已存在，
   建议改用真题语义色（`--real-bg` / `--real-line`）。
5. **`.ascii pre` 的深色面板**依赖 `--dark` / `--dark-fg`（已废弃旧名）。
   这个面板是 ASCII 图的阅读前提（等宽 + 高对比），替换时请保留一组
   中性的深色底/浅色字，别直接删掉。
6. 408 的 `--mw` 是 **780px**（正文宽），与契约一致。
