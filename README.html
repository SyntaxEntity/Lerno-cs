408 计算机学科专业基础综合 · 速成复习资料

面向已经系统学过 408、需要快速复习一遍的考生。全部内容以 Markdown 编写，可直接阅读或转换为 HTML。 每个知识点严格遵循统一六段式模板：考频统计 → 核心讲解 → 关键结论速记 → 示意图 → 易错点 → 真题示例。

二、数据来源与统计口径（重要，请先读）

本资料的考频数据并非官方发布，说明如下，以免误用：

  1. 统计区间：2009—2025 年 408 统考真题，共 17 套（2009 年为 408 首次统考年份）。
  2. "考察次数"的口径：按该考点在真题中被实际命题的题次计数；一道综合应用题若串联多个考点，则对每个直接考点各计 1 次（不重复计入同一考点在同一题内的多个小问）。
  3. 数据置信度分层： - 试卷结构、题型、题号区间与分值：依据官方考试大纲与公开试卷信息，高置信度。 - 各章分值占比：依据官方大纲，高置信度。 - 逐考点考察次数：依据王道《408 历年真题》、天勤辅导书等公开的考频统计表，并结合历年真题公开题面核对与自行统计，属中等置信度，允许 ±1 次误差。 - 凡无法核对到可靠统计的条目，一律标注 "考频待补充"，不作估算（本版 28 个知识点中，26 个有可核对数据； 2026 大纲新增的「绪论与算法分析」「计算机系统概述」两节标注「考频待补充」）。
  4. 真题示例的标注规则：能确证为原题的写"20XX 年 408 第 N 题"；对题面或题号无法完全确证的，写"20XX 年真题改编"，绝不伪装成原题。
  5. 本文档由脚本生成：正文数字与考频总表同源于 scripts/meta.py，并经 scripts/validate.py 校验，因此三处数字必然一致。

三、四科复习优先级（按"分值 × 命题稳定性"排序）

科目 建议顺序 理由
数据结构 树与二叉树 → 图 → 排序 → 查找 → 栈与队列 → 线性表 树 + 图合计约 30 分，且大题固定从这两章出
计算机组成原理 存储系统 → 中央处理器 → 数据表示与运算 → 指令系统 → 输入输出系统 → 总线 存储 + CPU 合计约 40 分；总线分值最低但公式固定，属必拿分

计算机网络 网络层 → 传输层 → 数据链路层 → 应用层 → 物理层 → 体系结构 网络 + 传输合计约 13 分，计算题模板化程度最高

六、如何重新生成与校验

bash
cd website/Lerno-cs
python3 scripts/run_all.py            # 一键跑通全链（推荐）
python3 scripts/validate.py --parts   # 校验 parts 半成品：模板字段、ASCII 对齐、mermaid 语法、真题年份
python3 scripts/build.py              # 由 parts + meta.py 生成四科 Markdown
python3 scripts/gen_summary.py        # 刷新本文件的考频总表
python3 scripts/build_quiz.py         # parts/quiz/*.json → assets/quiz-data.js（练习页题库）
python3 scripts/build_html.py         # 由 .docs/ 生成仓库根的静态站点
python3 scripts/validate.py           # 校验成品：模板、数字、图、链接、外壳、共用件、题库
python3 scripts/reverse_tests.py      # 反向测试：每条规则注入反例，确认真会报错
node scripts/test_quiz.mjs            # 练习页行为测试（jsdom；validate 的 F32 会跑它）

validate.py 的强制校验项包括（完整编号以它自己输出的「规则 N 条：…」为准； 编号存在历史空洞 F18—F21）：

  • F0 交付物完整性（文件非空、每个知识点含 ## 知识点 小节、四科半成品齐全）；
  • F1 每个知识点的六段式模板字段齐全且顺序正确；[高频] 标记必须与本节的「考频统计」双向一致——考频待补充不得标、有数据必须标（D-09）；
  • F2 正文的考频统计行与 scripts/meta.py 逐字一致（防止正文、总表、索引三处数字不一致）；
  • F3 代码块必须带 text/mermaid 语言标签、围栏成对闭合、mermaid 无孤立花括号与非法字符（含"圆括号未用引号包裹"这一会导致 mermaid 解析失败的写法）；
  • F4 禁止占位符（TODO / 待补充讲解 / XXX 等）；
  • F5 ASCII 图内不得出现全角字符或制表符（否则等宽对齐会被破坏）；
  • F6 真题年份必须落在 2009—2025；
  • F7 有考频数据的小节必须标 [高频]（warn 级；考频待补充的小节不告警）；
  • F8 每个知识点必须同时具备 ASCII 图与 Mermaid 图；
  • F9/F10/F11 核心讲解句数、易错点条数、关键结论速记条数在规范区间内；
  • F12 README 声明的"已核对原题"清单与正文标注双向逐条一致；
  • F13/F14 块级元素之间必须有空行，并用真实渲染器确认模板字段各自独立成段；
  • F15/F17 文档内相对链接可从仓库根解析，站点与归档的每个相对链接真实可达（含 .md 跳转页目标存在性）；
  • F16 HTML 产物与组件完整性（防止渲染器静默退化）；
  • F22 统一外壳完整性（顶栏 / 侧栏 / 章节翻页 / 页脚、六段锚点 id、首页科目卡片、每页恰好 1 个 h1、无重复 id 属性）；
  • F23 外置资源可达（assets/site.css、assets/site.js 被每个页面引用，页面无内联样式）；
  • F24 渲染后不得残留字面 **（成品与内容源都查）；
  • F25 共用件与上游 Lerno-math 逐字节一致（文件头钉 sha256；同工作区有兄弟仓库时再做一次逐字节比对）；
  • F26 外壳行为测试（用 jsdom 真跑 assets/site.js 的 12 条断言）；
  • F27 元校验（规则集合 ≡ 反向测试覆盖集合、扫描型规则的受检对象数大于 0）；
  • F28 文档与 CI 不得硬编码规则范围；
  • F29 site.css 语法自检（花括号/圆括号/方括号配平、规则头完整、@media 块配平）；

七、使用建议（时间紧张时）

  2. 每节只读三段：考频统计 判断要不要细看 → 关键结论速记 快速回忆公式 → 易错点 排雷；核心讲解 在回忆不起来时再读。
  3. 图形优先：示意图 中的 ASCII 图与 Mermaid 图是"考场默写"的模板，尤其是 Cache 地址划分、IP 分片、流水线时空图、五状态转换图、TCP 握手挥手这几张。
  4. 真题示例当自测：先不看解析作答，再对照解析检查推导链是否完整。

八、配套练习（练习闭环）

每章读完可以到 练习.html 做一组题：今日计划 → 刷题 → 即时判分 → 错题本 → 掌握度 → 学习报告 → 次日计划，另有三种限时模拟（全科 20 题 / 单科 15 题 / 薄弱点 10 题）。

  • 题目规模：155 道单选题，覆盖 28 个知识点（每个 5—10 题）；其中 144 道改编自授权题库、 11 道自编，来源、审校与考纲核对记录见 parts/quiz/README.md。
  • 数据只在本机：作答、错题、掌握度都存在浏览器本地，不上传任何服务器； 换设备前请在练习页「设置 → 导出备份」。
  • 两套判定：考点掌握度按累计答对（≥4 次「已掌握」、≥2 次「复习中」）； 错题按连续答对 2 次判「已掌握」。
  • 和正文的关系：练习只是补充，不替代阅读；每道题都标了所属知识点，可跳回对应章节。
