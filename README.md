## 三、⚠️ 数据口径与可信度（请先读）

**考频数据不是官方发布**，使用前请了解其边界：

1. **统计区间**：`2009—2025` 年 `408` 统考真题，共 `17` 套。
2. **"考察次数"口径**：按该考点被实际命题的题次计数；一道综合题串联多个考点时各计 `1` 次。
3. **可信度分层**：试卷结构/题型/分值依据官方大纲（高）；逐考点考察次数参考公开考频统计
   资料并结合真题题面整理（**中等，允许 ±1 次误差**）。凡无法核对的一律标注"考频待补充"，
   本版 26 个知识点均有可核对数据。
4. **真题标注分两级**，不冒充原题：
   - `**20XX 年 408 第 N 题（题型，X 分）**`：题面经公开题库逐条核对（`17` 道）；
   - `**20XX 年真题改编**`：考点与考法保留，题面为改写或年份题号无法确证（`11` 道）。
5. **⚠️ 本站线上总览页（`README.html`）渲染的不是本文件**：它由 `.docs/00-总览.md` 生成。
   两份文档内容高度重叠但**各自独立维护**，改数据口径/校验项说明时**必须同时改两处**，
   否则会出现"仓库说明与线上说明不一致"。本文件另被 `validate.py` 的 `F12` 用作
   "已核对原题"声明的比对基准，因此不可删除。
6. **完整来源与许可说明见 [`LICENSE`](LICENSE)**：原创讲解/图示/代码按 CC BY-NC-SA 4.0 开放；
   **真题题面属公开试题、权利归原考试机构，不在本许可范围内**，仅作教育性少量引用。


**外壳与 math2-kaoyan 对齐**：两站的页面骨架用同一份 DOM 结构与 class 名
（顶栏 `.site-topbar`、面包屑 `.tb-crumbs`、侧栏 `.site-sidebar`、
六段锚点 `#sec-freq … #sec-real`、章节导航 `.chapter-nav`、页脚 `.site-footer`、
首页卡片 `.home-subjects`），规格见 `../PLAN-对齐与改版.md`。
**统一的是结构与类名，不是视觉**——配色由各自的 `assets/site.css` 决定。

**为什么既有网页又有 Markdown**：网页是给人读的成品；Markdown 是**可校验**的成品，
也是"改内容 → 重新生成 → 自动校验"这条链的产物，删掉就无法再自动校验了。

## 五、部署到静态托管

站点就在仓库根目录，**无需任何构建步骤、无需后端**，平台选"从根目录发布"即可。
已实测：全部资源相对路径、无外部 `http` 依赖、体积约 `8 MB`。

| 平台 | 要点 |
| --- | --- |
| **GitHub Pages** | 本仓库已带工作流 `.github/workflows/pages.yml`：推 `main` 即自动发布，且**发布前先跑 `scripts/validate.py`**（形式校验），校验不过不会上线；免费账户需**公开仓库** |
| **Cloudflare Pages** | 免费、可连**私有**仓库、国内连通性通常较好 |
| Vercel / Netlify | 直接导入仓库，Framework 选 Other，Output 留空 |

> 仓库根已有空的 `.nojekyll`，Jekyll 不会插手，纯静态站点按原样发布。

## 六、本地再生成与校验

工具链依赖 Python 与（可选的）Node 依赖：

```bash
# 一次性安装依赖（.tools/ 已 gitignore，可随时删掉重建）
python3 -m venv .tools/venv
.tools/venv/bin/python -m pip install -r scripts/requirements.txt
npm install --prefix .tools --cache /tmp/npm-cache --no-audit --no-fund \
  mermaid@12.1.0 jsdom@30.1.2        # 版本见 scripts/tools-package.json

# 一键跑通全流水线（推荐）：规范化 → 分段 → 组装 → 总表 → 站点 → 校验
python3 scripts/run_all.py           # 加 --quick 可跳过规范化与分段

# 或按需单步执行（顺序不可颠倒）
python3 scripts/normalize_md.py      # Markdown 空行规范化（幂等）
python3 scripts/split_explain.py     # 长段落自动分段
python3 scripts/build.py             # 由 parts/ + meta.py 组装 .docs/ 的 Markdown
python3 scripts/gen_summary.py       # 刷新 .docs/00-总览.md 的考频总表
python3 scripts/build_html.py        # 由 .docs/ 生成仓库根的静态站点
python3 scripts/validate.py          # 校验形式层，含 mermaid 真实解析
python3 scripts/validate.py --parts  # 校验 parts/ 半成品（写内容时的内层循环）
```

依赖版本由 `scripts/requirements.txt` 与 `scripts/tools-package.json` 锁定，
不再散落在命令或工作流里——**本地校验与 CI 门禁用的是同一套版本**，否则"门禁通过"
不等于"本地通过"。其中 `mermaid` 的版本必须等于仓库根 `mermaid.min.js` 的版本，
`validate.py` 会在两者不一致时直接报错。

`validate.py` 的形式校验项（范围见运行输出）：模板字段齐全与顺序、考频数字与单一数据源逐字一致、
代码块与图语法（**含 mermaid 真实解析，缺依赖即报错而非跳过**）、ASCII 图全角字符、
真题年份、图数量、段落与条目数区间、README 声明与正文标注双向一致、块级元素空行、
**渲染验证字段独立成段**、相对链接可达、交付物与组件完整性（防止渲染器静默退化）、
**全站断链校验（含 `.md` 跳转页目标存在性）**、
**`F22` 统一外壳完整性**（顶栏/面包屑/侧栏/页脚四件齐全、六段锚点齐备、
章节 prev/next 首末章正确、首页科目卡片数 = 科目数）、
**`F23` 外置资源可达**（`assets/site.css|site.js` 存在且被每个页面引用、页面无内联样式）、
**`F24` 渲染残留**（正文不得露出字面 `**`，成品与内容源都查）、
**`F25` 共用件一致性**（`assets/site.js` 正文必须与上游 `math2-kaoyan` 逐字节相同，
靠文件头钉的 sha256 强制）、**`F26` 外壳行为测试**（jsdom 跑 12 条断言，复用数学二的测试）。

**规则范围由校验器自己输出**（见运行报告末尾的「规则 N 条：…」）——编号存在历史
空洞（`F18`—`F21` 从未使用），所以文档与 CI 都**不写死范围**，避免加规则后漂移。

**没有反向测试的校验项进不了主干**：`scripts/reverse_tests.py` 对每条规则注入一个
反例、断言它真的报错（`python3 scripts/reverse_tests.py`），CI 在形式校验之后跑它，
失败即中止部署。元校验 `F27` 用**集合比较**强制"规则集合 ≡ 反向测试覆盖集合"，
并要求扫描型规则上报的**受检对象数 > 0**（防止 glob 写错时"空转通过"）；
`F28` 禁止文档/CI 硬编码规则范围。

外壳相关的校验项都是**契约**（`../PLAN-对齐与改版.md` 2.4），不是本仓库的偏好；
要改类名/锚点 id 请先改契约，再同步两个项目。

## 七、修改内容请只改 `parts/`

`parts/` 是内容源，`scripts/build.py` 会把统计数字与模板骨架注入 `.docs/`。
**不要直接改 `.docs/` 或站点 HTML**，重新生成会覆盖。
