## 三、⚠️ 数据口径与可信度（请先读）

**考频数据不是官方发布**，使用前请了解其边界：

1. **统计区间**：`2009—2025` 年 `408` 统考真题，共 `17` 套。
2. **"考察次数"口径**：按该考点被实际命题的题次计数；一道综合题串联多个考点时各计 `1` 次。
3. **可信度分层**：试卷结构/题型/分值依据官方大纲（高）；逐考点考察次数参考公开考频统计
   资料并结合真题题面整理（**中等，允许 ±1 次误差**）。凡无法核对的一律标注"考频待补充"，
   本版 26 个知识点均有可核对数据。
4. **真题标注分两级**，不冒充原题：
   - `**20XX 年 408 第 N 题（题型，X 分）**`：题面经公开题库逐条核对（`17` 道）；
   - `**20XX 年真题改编**`：考点与考法保留，题面为改写或年份题号无法确证（`11` 道）。
5. **完整来源与许可说明见 [`LICENSE`](LICENSE)**：原创讲解/图示/代码按 CC BY-NC-SA 4.0 开放；
   **真题题面属公开试题、权利归原考试机构，不在本许可范围内**，仅作教育性少量引用。

**为什么既有网页又有 Markdown**：网页是给人读的成品；Markdown 是**可校验**的成品，
也是"改内容 → 重新生成 → 自动校验"这条链的产物，删掉就无法再自动校验了。

## 五、部署到静态托管

站点就在仓库根目录，**无需任何构建步骤、无需后端**，平台选"从根目录发布"即可。
已实测：全部资源相对路径、无外部 `http` 依赖、体积约 `8 MB`。

| 平台 | 要点 |
| --- | --- |
| **Cloudflare Pages** | 免费、可连**私有**仓库、国内连通性通常较好（推荐） |
| GitHub Pages | 仓库 Settings → Pages → Source 选 `main` / `root`；**公开仓库才免费** |
| Vercel / Netlify | 直接导入仓库，Framework 选 Other，Output 留空 |

> 若平台用 Jekyll 处理，本仓库不含下划线开头的站点目录，无需额外配置；
> 如遇问题可加一个空的 `.nojekyll` 文件。

## 六、本地再生成与校验

工具链依赖 Python 与（可选的）Node 依赖：

```bash
python3 scripts/normalize_md.py    # Markdown 空行规范化（幂等）
python3 scripts/split_explain.py   # 长段落自动分段
python3 scripts/build.py           # 由 parts/ + meta 数据组装 .docs/ 的 Markdown
python3 scripts/gen_summary.py     # 刷新 .docs/00-总览.md 的考频总表
python3 scripts/build_html.py      # 由 .docs/ 生成仓库根的静态站点
python3 scripts/validate.py        # 校验：模板/数字一致性/图/链接/组件

# 可选：真实 Mermaid 语法校验（需要 node 依赖）
npm install --prefix .tools mermaid jsdom
node scripts/check_mermaid.mjs
```

`validate.py` 覆盖 `F1`—`F17`：模板字段齐全与顺序、考频数字与单一数据源逐字一致、
代码块与图语法、ASCII 图全角字符、真题年份、图数量、段落与条目数区间、
README 声明与正文标注双向一致、块级元素空行、**渲染验证字段独立成段**、
相对链接可达、交付物与组件完整性（防止渲染器静默退化）、
**全站断链校验（含 `.md` 跳转页目标存在性）**。

## 七、修改内容请只改 `parts/`

`parts/` 是内容源，`scripts/build.py` 会把统计数字与模板骨架注入 `.docs/`。
**不要直接改 `.docs/` 或站点 HTML**，重新生成会覆盖。
