## 二、数据来源与统计口径（重要，请先读）

本资料的**考频数据并非官方发布**，说明如下，以免误用：

1. **统计区间**：`2009—2025` 年 `408` 统考真题，共 `17` 套（`2009` 年为 `408` 首次统考年份）。
2. **"考察次数"的口径**：按该考点在真题中**被实际命题的题次**计数；一道综合应用题若串联多个考点，则对每个直接考点各计 `1` 次（不重复计入同一考点在同一题内的多个小问）。
3. **数据置信度分层**：
   - **试卷结构、题型、题号区间与分值**：依据官方考试大纲与公开试卷信息，**高置信度**。
   - **各章分值占比**：依据官方大纲，**高置信度**。
   - **逐考点考察次数**：依据王道《408 历年真题》、天勤辅导书等公开的考频统计表，并结合历年真题公开题面核对与自行统计，属**中等置信度，允许 ±1 次误差**。
   - 凡无法核对到可靠统计的条目，一律标注 **"考频待补充"**，不作估算（本版 26 个知识点均有可核对数据，故未出现该标注）。
4. **真题示例的标注规则**：能确证为原题的写"**20XX 年 408 第 N 题**"；对题面或题号无法完全确证的，写"**20XX 年真题改编**"，**绝不伪装成原题**。
5. **本文档由脚本生成**：正文数字与考频总表同源于 `scripts/topics.py`，并经 `scripts/validate.py` 校验，因此三处数字必然一致。

## 三、四科复习优先级（按"分值 × 命题稳定性"排序）

| 科目 | 建议顺序 | 理由 |
| --- | --- | --- |
| 数据结构 | 树与二叉树 → 图 → 排序 → 查找 → 栈与队列 → 线性表 | 树 + 图合计约 `30` 分，且大题固定从这两章出 |
| 计算机组成原理 | 存储系统 → 中央处理器 → 数据表示与运算 → 指令系统 → 输入输出系统 → 总线 | 存储 + CPU 合计约 `40` 分；总线分值最低但公式固定，属必拿分 |
| 操作系统 | 内存管理 → 同步与互斥 → 进程与线程 → 调度与死锁 → 文件管理 → I/O 管理 → 概述 | 内存 + 同步互斥合计约 `16` 分且大题命中率最高 |
| 计算机网络 | 网络层 → 传输层 → 数据链路层 → 应用层 → 物理层 → 体系结构 | 网络 + 传输合计约 `13` 分，计算题模板化程度最高 |

## 六、如何重新生成与校验

```bash
cd website/408-kaoyan
python3 scripts/validate.py --parts   # 校验 parts 半成品：模板字段、ASCII 对齐、mermaid 语法、真题年份
python3 scripts/build.py              # 由 parts + topics.py 生成四科 Markdown
python3 scripts/gen_summary.py        # 刷新本文件的考频总表
python3 scripts/validate.py           # 校验成品：模板完整性、考频数字一致性、图表数量
```

`validate.py` 的强制校验项包括：

- `F1` 每个知识点的六段式模板字段齐全且**顺序正确**；
- `F2` 正文的**考频统计行与 `topics.py` 逐字一致**（防止正文、总表、索引三处数字不一致）；
- `F3` 代码块必须带 `text`/`mermaid` 语言标签、围栏成对闭合、`mermaid` 无孤立花括号与非法字符（含"圆括号未用引号包裹"这一会导致 mermaid 解析失败的写法）；
- `F5` **ASCII 图内不得出现全角字符或制表符**（否则等宽对齐会被破坏）；
- `F6` 真题年份必须落在 `2009—2025`；
- `F8` 每个知识点必须同时具备 ASCII 图与 Mermaid 图；
- `F9`/`F10`/`F11` 核心讲解句数、易错点条数、关键结论速记条数在规范区间内；
- `F12` README 声明的"已核对原题"清单与正文标注**双向逐条一致**；
- `F13`/`F14` 块级元素之间必须有空行，并用真实渲染器确认模板字段各自独立成段；
- `F15`/`F17` 文档内相对链接可从仓库根解析，站点与归档的每个相对链接真实可达（含 `.md` 跳转页目标存在性）；
- `F16` HTML 产物与组件完整性（防止渲染器静默退化）。

除静态规则外，还可用官方 `mermaid` 解析器做**真实语法校验**：脚本会把全部 `52` 张 Mermaid 图逐张交给 `mermaid.parse()`，全部解析通过才算合格（这一层能发现静态规则看不出、但渲染时必然报错的写法）。

```bash
npm install --prefix .tools mermaid jsdom   # 一次性准备，.tools/ 已在 .gitignore 中忽略
node scripts/check_mermaid.mjs              # 期望输出：mermaid 图总数 52，解析失败 0
```

## 七、使用建议（时间紧张时）

1. **只看 `[高频]` 小节**：本版 26 个知识点全部标记为 `[高频]`（均在统计区间内反复命题），若时间极紧，按第三节的优先级顺序逐个过。
2. **每节只读三段**：`考频统计` 判断要不要细看 → `关键结论速记` 快速回忆公式 → `易错点` 排雷；`核心讲解` 在回忆不起来时再读。
3. **图形优先**：`示意图` 中的 ASCII 图与 Mermaid 图是"考场默写"的模板，尤其是 Cache 地址划分、`IP` 分片、流水线时空图、五状态转换图、`TCP` 握手挥手这几张。
4. **真题示例当自测**：先不看解析作答，再对照解析检查推导链是否完整。
